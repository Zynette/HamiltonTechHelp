Remote tech help, without the house call.

01 / WHAT I CAN LOOK AT

What I can look at

  • Outlook, Microsoft 365 and OneDrive setup or troubleshooting
  • Windows and Mac software problems and new computer setup
  • Printer connections, file transfers and basic connectivity
  • Everyday Apple-device questions that can be handled remotely
02 / WHAT IS OUTSIDE SCOPE

What is outside scope

  • Physical repairs, broken parts, batteries and liquid damage
  • Advanced data recovery, serious security incidents and emergency support
  • Access to third-party-managed devices without their IT team’s explicit authorization
03 / HOW A SESSION WORKS

How a session works

  • Describe the issue and device first; I assess whether remote work is suitable.
  • Review a written scope, price and proposed time before approving anything.
  • When a session is arranged, you control temporary access and can end it. No unattended access is promised.
