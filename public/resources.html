A little knowledge to keep.

Ten practical checklists. Free to read, print and download. No email address needed.

Computer spring cleaning

Save your work before restarting. Review the files in Downloads and identify what you still need. Make a separate backup before removing anything. Check available storage in system settings. Install updates through your operating system's own update screen. Wipe the outside with the device powered off, following the manufacturer's cleaning instructions.

Recognize suspicious emails

Pause when a message pressures you to act quickly. Check the full sender address, even when the display name looks familiar. Reach the organization through its app or a website you already know. Avoid unexpected attachments and sign-in links. A polished message can still be fraudulent. If you shared account access, use the provider's official recovery process and tell the affected organization.

New computer setup checklist

Keep your old computer and its files until you have checked the new one. Connect to a trusted network. Install system updates. Download applications from their official publishers. Set up your own sign-in and recovery options privately. Copy a small group of files first and open them on the new device. Set up a separate backup and test that you can retrieve one file.

Basic Windows maintenance

Save and close your work before a planned restart. Check Windows Update in Settings. Review available storage without deleting unfamiliar system folders. Keep security protection enabled. Review startup apps and ask for help before changing unfamiliar items. Back up important files and keep recovery information somewhere private. On a work-owned device, ask your organization before installing software or changing settings.

Basic Mac maintenance

Use System Settings to review software updates and storage. Save your work before restarting. Keep a backup on a suitable separate drive. Time Machine can make scheduled backups, but setting up a disk can require erasing it: stop if it contains files you need. Check that a recent backup exists. Avoid cleanup apps that make unfamiliar changes. Ask before modifying a work-managed Mac.

Organize your files

Start with a small folder. Use clear names that describe the contents and include dates when helpful. Keep related documents together. Make a copy before reorganizing a large collection. Check whether folders sync to a cloud account: moving or deleting there may affect other devices. Keep originals until you have verified copies. Avoid storing account passwords in ordinary documents.

OneDrive basics

Check which account is signed in. Open the OneDrive cloud icon to read its status. A cloud-only file may need an internet connection to open. If syncing is paused, resume it from the OneDrive menu when ready. Check available cloud storage when files stop uploading. Deletion can sync to other devices, so keep a separate backup of important files. Avoid unlinking accounts or resetting the app as a first step.

Back up important photos

Identify where the original photos are stored. Copy them to a second trusted location. If originals live in the cloud, confirm they have downloaded before copying. Open several copies, including an older photo and a video. Keep the originals until verification is complete. Disconnect an external backup drive safely when finished. A synced library can repeat accidental deletion; a separate backup adds another recovery option.

Prepare for a business website

Write down your main customer and the action you want them to take. Gather service descriptions, approved prices and contact information. Choose examples of work you have permission to show. Confirm who owns the domain and hosting accounts. List required pages and forms. Agree on revisions, testing, timeline, handover and ongoing costs in the written quote. Share access through the provider's permission tools when possible.

Essential digital safety

Use a unique password for each important account and a trusted password manager if suitable. Turn on multi-factor authentication where offered. Keep recovery methods current and private. Install updates through official channels. Verify unexpected requests through a separate contact method. Never give remote access to an unsolicited caller. Keep a separate backup of important information.
